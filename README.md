
The **Deepthi R CSE Portfolio** is a responsive personal portfolio website designed to present my academic background, technical skills, projects, and professional contact information in a clean and user-friendly interface.

The project was developed and improved progressively through the internship modules.

---

## ✨ Features

- 🏠 Home section
- 👩‍💻 About Me section
- 🎓 Education section
- 💻 Technical Skills section
- 📂 Projects section
- 📧 Contact section
- 🔗 GitHub and LinkedIn links
- 📄 Resume download
- 🌙 Dark/Light mode
- 📱 Responsive mobile navigation
- ✨ Scroll animations
- ⬆️ Back-to-top button
- 📅 Automatic copyright year
- ✅ Contact form validation
- 📱 Mobile, tablet, and desktop responsive design
